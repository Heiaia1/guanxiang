# 《观象录》微信开发者工具与真机手工验收

版本：1.0
文档日期：2026-07-31
适用范围：第一版全本地 MVP

## 1. 验收原则

- 只把实际执行并观察到的项目标为通过。
- 本地编译通过不能代替微信体验版和真机验收。
- 模拟器通过不能代替 iOS、Android 的动画、Storage、分享和安全区检查。
- 自动化测试通过不能代替内容、安全提示和中文排版检查。
- 发现失败后先修复根因，再回归相关流程和受影响旧功能。
- 测试版本必须与计划上传的源码状态一致，避免在测试后继续改代码而未复测。

建议至少覆盖：

- 一台当前仍在支持范围内的 iPhone。
- 一台 Android 手机。
- 一台性能较低或使用省电模式的 Android 手机；若暂时没有第三台设备，应在现有 Android 上开启省电设置并降低系统可用资源进行补充检查。
- 微信开发者工具中一个小屏模拟器和一个长屏模拟器。

真实设备型号、系统版本、微信版本、基础库、测试时间和测试人员应记录到每次发布工单或版本记录中，不在本说明中虚构固定结果。

## 2. 验收前准备

- [ ] 使用项目锁定的 Node.js 和包管理工具安装依赖，安装过程无未解释错误。
- [ ] 项目静态检查、类型检查和自动化测试通过。
- [ ] `project.config.json` 存在并指向实际小程序目录。
- [ ] 微信开发者工具已登录具有该 AppID 权限的账号；本地开发可使用明确的测试 AppID，但上传前必须切换为发布 AppID。
- [ ] 开发者工具基础库版本与项目支持范围一致。
- [ ] 清楚本版本不使用后端、AI、登录、支付、广告或远程内容。
- [ ] 已阅读 `product-plan.md`、`content-rules.md`、`test-cases.md`、`privacy-policy.md` 和 `submission-checklist.md`。
- [ ] 发布候选版本不含调试按钮、模拟结果开关、隐藏入口或测试数据。
- [ ] 微信开发者工具已打开 Console、Network、Storage 和性能相关面板，便于观察。

## 3. 导入与首次编译

1. 打开微信开发者工具。
2. 选择“小程序”并导入包含 `project.config.json` 的项目根目录。
3. 确认 AppID、项目名称和小程序源码目录来自当前项目。
4. 执行“编译”。
5. 查看 Console：
   - 不应有脚本异常。
   - 不应有页面或组件找不到。
   - 不应有 JSON 解析失败。
   - 不应有未声明接口、权限或隐私相关错误。
6. 查看 Network：
   - 完整业务流程不应发出项目业务网络请求。
   - 微信开发者工具自身或平台框架请求应与项目业务请求区分。
7. 查看 Storage：
   - 首次进入前不应出现虚构用户记录。
   - 同意说明、设置和保存结果后只出现预期的本地键值。
8. 重新编译和热重载各一次，确认状态恢复逻辑一致。

若导入失败，应先核对路径、AppID、源码目录和配置文件，不应新建第二套重复项目来绕过现有配置。

## 4. 首次启动与使用说明

- [ ] 全新清理 Storage 后启动，首先进入启动动画。
- [ ] 启动动画持续约 2—3 秒，用户可立即跳过。
- [ ] 跳过只触发一次导航，不出现闪屏、重复页面或无响应。
- [ ] 首次说明明确“传统文化互动与个人反思”“不代表未来必然发生”“不构成医疗、法律、投资建议”。
- [ ] “我已了解，开始体验”按钮可见、可点击，不被安全区遮挡。
- [ ] 接受后进入首页，并保存已阅读状态。
- [ ] 关闭再打开后不重复强制展示首次说明。
- [ ] 设置页仍可重新查看产品说明、隐私保护说明和用户协议。
- [ ] 不接受时可返回或退出，不使用倒计时或遮挡强迫同意。

## 5. 首页与导航

- [ ] 首页展示“今日观象”“问一件事”“六十四卦”“我的记录”和设置入口。
- [ ] 首页不出现今日运势、财运、桃花、吉凶、改运、消灾或大师字样。
- [ ] 所有入口都有点击反馈并能打开正确页面。
- [ ] 连续快速点击入口不会重复压入相同页面。
- [ ] 每个二级页面均有可理解的返回路径。
- [ ] 从深层页面返回首页后，首页按钮仍可操作。
- [ ] 底部导航、浮动按钮和主要文字不被系统安全区遮挡。
- [ ] 页面背景动效不拦截按钮点击和滚动。

## 6. 普通情境完整流程

至少分别执行一次六个领域，另外按 `test-cases.md` 完成全部 54 个普通问题。

标准主流程：

1. 首页点击“问一件事”。
2. 选择“工作事业”。
3. 输入“我想辞职，但还没有找到下一份工作，现在应该走吗？”。
4. 选择：
   - 正在准备。
   - 有很多未知情况。
   - 主要由我决定。
   - 可能影响基本生活。
   - 焦虑。
5. 进入生成方式选择。
6. 选择“情境生成”。
7. 等待六爻完成并查看结果。

核对：

- [ ] 六类领域均存在且选择状态清晰。
- [ ] 问题输入提示不要填写姓名、生辰、地址等个人信息。
- [ ] 空问题和纯空格不能提交。
- [ ] 1 个有效字符可提交，100 个字符可完整显示，超过限制有明确反馈。
- [ ] 中文、英文、数字、标点和 emoji 不乱码。
- [ ] 五道状态题未完成时不能进入下一步，并明确指出未完成项。
- [ ] 返回上一页后已填内容按产品规则恢复，不出现其他用户或旧流程数据。
- [ ] 快速连点“下一步”只导航一次。
- [ ] 结果至少关联“准备不足或信息未知”和“基本生活风险”。
- [ ] 结果不直接命令辞职或留下，不预测成功、破财或灾祸。
- [ ] 结果含今天、七天内和重新决定条件三条不同建议。
- [ ] 古籍原文和现代解释视觉上有区别。
- [ ] 理性使用提示可见。
- [ ] 从结果页进入单卦详情，卦名和卦象一致。

## 7. 确定性检查

1. 记录一次情境模式的领域、问题、五个答案、卦名、上下卦、变化爻、摘要和三步行动。
2. 不修改任何输入，回到流程重复执行 10 次。
3. 完全关闭小程序后重新打开，再执行一次。

通过条件：

- [ ] 同一内容版本下，11 次的上下卦、变化爻、核心摘要和三步行动一致。
- [ ] 没有因时间、设备、点击速度或历史记录数量改变结果。
- [ ] 修改“失败影响”为“影响很小”后重新生成，结果能反映风险变化。
- [ ] 返回修改答案后不存在旧答案或旧卦象残留。
- [ ] 铜钱模式的随机行为不会污染情境模式的确定性。

## 8. 铜钱互动与动效

- [ ] 进入前明确显示“传统文化互动，不构成现实预测”。
- [ ] 通过产品定义的点击或上滑动作完成六次投掷。
- [ ] 每次只增加一条爻线，顺序从下向上。
- [ ] 三枚铜钱旋转、落下和结果反馈不遮挡操作。
- [ ] 前两次完整、中间三次加快、最后一次收束，整体等待时间可接受。
- [ ] 阳爻、阴爻和变化爻视觉可区分但不过度闪烁。
- [ ] 动画播放期间快速连点不会多生成爻线。
- [ ] 切后台、锁屏后返回，不会跳过、重复或保存两次。
- [ ] Canvas 初始化失败时能显示静态或简化降级视图。
- [ ] 音效失败或系统静音不阻塞流程。
- [ ] 不支持震动的设备仍可完成流程。
- [ ] 页面没有“重测到满意”“分享改结果”或付费重测。

## 9. 今日观象

- [ ] 可选择平静、焦虑、犹豫、有冲劲、疲惫和想改变。
- [ ] 每个状态都有文化主题、反思问题和当天行动。
- [ ] 同一自然日、同一状态重复打开结果一致。
- [ ] 切换状态后内容能体现对应差异。
- [ ] 不显示财运、桃花、健康预测、吉凶或具体未来事件。
- [ ] 当天行动具体、低风险且可由用户执行。
- [ ] 页面标题和分享文案使用“今日观象”，不使用“今日运势”。

## 10. 高风险拦截

至少执行 `test-cases.md` 中 18 个高风险样本，并重点实测：

- 自伤或自杀。
- 伤人或报复。
- 家庭暴力和立即危险。
- 胸痛、肿块、停药和生育预测。
- 诉讼胜负与销毁证据。
- 股票、借钱炒币、彩票和网贷翻本。
- 偷看聊天、跟踪住址。
- 他人寿命。

逐项核对：

- [ ] 提交后直接进入对应安全提示，不播放生成动画。
- [ ] 页面不显示卦名、变化爻或吉凶。
- [ ] 自伤、伤人和暴力场景优先建议现实安全行动。
- [ ] 医疗场景不诊断、不解释检查、不调整用药。
- [ ] 法律场景不预测胜诉、不帮助毁灭证据或逃避责任。
- [ ] 投资和赌博场景不提供标的、仓位、回报、号码或“时机”。
- [ ] 隐私场景不提供窃取账号、定位或跟踪方法。
- [ ] 安全提示语气直接、尊重，不使用玄学原因或羞辱文案。
- [ ] 页面允许返回修改问题或回到首页。
- [ ] 使用同音字、插入空格、大小写和常见变体复测关键高风险表达。
- [ ] 普通文化问题不会因单个无害字词被错误拦截。

## 11. 六十四卦文化馆

- [ ] 列表共 64 项，ID 和卦名不重复。
- [ ] 每项显示卦名、读音、上下卦或核心关键词。
- [ ] 每一项都能打开对应详情。
- [ ] 详情包含上下卦、卦象图、关键词、古籍原文、白话解释和行动启示。
- [ ] 传统原文与现代解释样式明确区分。
- [ ] 返回列表后滚动位置合理。
- [ ] 从结果页进入详情时打开正确卦象。
- [ ] 收藏和取消收藏立即更新，并在重启后保持。
- [ ] 同一卦重复收藏不会生成重复收藏项。
- [ ] 长文本滚动流畅，不被底部按钮遮挡。
- [ ] 逐项抽查中文读音、上下卦和六爻图形一致。
- [ ] 数据解析失败时显示可恢复错误，不跳到其他卦或展示空白。

## 12. 历史、删除与容量

- [ ] 结果页选择保存后，历史立即出现对应记录。
- [ ] 选择“不保存本次”后历史不新增。
- [ ] 历史项显示日期、领域、卦名和摘要。
- [ ] 打开历史详情后，问题、卦象和三步行动与保存时一致。
- [ ] 删除单条前有明确二次确认。
- [ ] 取消删除不改变任何数据。
- [ ] 确认删除后立即消失，重启后不恢复。
- [ ] 清空全部前有二次确认，文案说明影响范围。
- [ ] 清空记录不误删收藏和设置。
- [ ] 连续保存至 100 条后仍可正常打开和滚动。
- [ ] 写入第 101 条时移除最旧的非收藏记录。
- [ ] 最旧记录为收藏时保留它，并移除下一条最旧的非收藏记录。
- [ ] Storage 数据损坏或字段缺失时不崩溃，不覆盖仍可读取的设置。
- [ ] 既有无版本 Storage 首次读取后只新增 `gx_meta`，原记录、草稿、收藏和设置逐字节保持不变。
- [ ] 模拟一次读取异常后，保存、删除、收藏和设置更新均不覆盖旧值；恢复读取后旧值仍可查看。
- [ ] 将元数据版本改为高于当前版本后，页面显示升级提示，所有普通写入均被拒绝且旧数据保持不变。
- [ ] 设置结构损坏时可由用户明确选择恢复默认设置；记录结构损坏时只有二次确认后才能清理记录和草稿。
- [ ] 本地容量不足时显示清晰错误，不谎称已保存。

## 13. 设置与隐私

- [ ] 动画、音效、震动、省电和默认保存开关均可操作。
- [ ] 每个设置修改后立即生效。
- [ ] 关闭并重新打开后设置保持。
- [ ] 关闭动画后，启动、六爻和页面流程仍可完成。
- [ ] 关闭音效后不创建或播放新的音频。
- [ ] 关闭震动后不调用震动反馈。
- [ ] 开启省电模式后粒子、阴影或持续动效按设计降级。
- [ ] 隐私保护说明可以完整阅读。
- [ ] 用户协议可以完整阅读。
- [ ] 文档中的数据处理与实际 Storage、权限和分享行为一致。
- [ ] 设置页能找到删除单条和清空全部的实际入口或明确导航。
- [ ] 不存在定位、相机、相册、麦克风、手机号、通讯录、蓝牙或运动数据授权请求。

## 14. 分享隐私

在普通结果、今日观象和单卦详情分别触发分享：

- [ ] 分享必须由用户主动操作触发。
- [ ] 分享标题不含用户原问题。
- [ ] 分享卡不含状态答案、情绪、备注、历史时间或记录 ID。
- [ ] 分享路径参数不能恢复问题或本地记录。
- [ ] 卡面只显示卦象、卦名、中性关键词、文化解释或行动提醒。
- [ ] 不出现“转发解锁”“分享增加好运”等诱导。
- [ ] 接收方打开后进入公开安全页面，不看到分享者本地数据。
- [ ] 用户取消分享后不改变结果、不保存额外数据。

## 15. 断网与业务网络请求

### 开发者工具

1. 清空 Network 面板。
2. 依次完成首次说明、情境分析、铜钱互动、文化馆、历史、设置和分享前页面。
3. 过滤项目域名、`request`、`uploadFile`、`downloadFile`、WebSocket 和远程图片。

通过条件：

- [ ] 没有项目业务网络请求。
- [ ] 没有远程 JSON、字体、图片、音效或配置。
- [ ] 没有 AI、统计、广告、登录、支付或日志上报。

### 真机

1. 先正常安装或打开体验版。
2. 开启飞行模式并保持 Wi-Fi 关闭。
3. 重新进入已经安装的体验版。
4. 完成情境分析、文化馆、历史和设置流程。

通过条件：

- [ ] 在微信平台允许打开已安装体验版的前提下，核心业务无需联网。
- [ ] 断网不会出现无限加载、空白页或伪造成功提示。
- [ ] 本地图形、设备端程序合成音效和六十四卦内容仍可使用。
- [ ] 恢复网络后本地记录不重复、不丢失。

## 16. 适配与可用性

在小屏、长屏、iOS、Android 和系统字体放大下检查：

- [ ] 状态栏、胶囊按钮、安全区和键盘不会遮挡导航与提交按钮。
- [ ] 页面标题、问题、卦名、古籍和行动建议不截断。
- [ ] 长文本可滚动到末尾。
- [ ] 输入框获得焦点时，当前字段和提交反馈仍可见。
- [ ] 横竖屏切换或系统恢复后页面不崩溃；若产品固定竖屏，应稳定保持竖屏布局。
- [ ] 文字与背景对比清楚，朱砂提示不作为唯一状态区分。
- [ ] 可点击区域足够，连续操作不会误触相邻按钮。
- [ ] 动画关闭后仍能理解当前步骤和生成结果。
- [ ] 系统深色模式不会把文字、图标或表单变成不可见。
- [ ] 中文标点、英文和数字混排无异常换行。

## 17. 稳定性与性能

- [ ] 冷启动后主操作在合理时间内可用，无长时间白屏。
- [ ] 启动动画可在任何时刻跳过。
- [ ] 页面切换不因装饰动画被阻塞。
- [ ] 连续完成 20 次情境分析无崩溃、重复导航或明显持续变慢。
- [ ] 连续浏览 64 个卦象详情后返回首页正常。
- [ ] 高频进入和退出铜钱页不残留多个动画计时器或音频实例。
- [ ] 切后台 1 分钟后返回，页面状态合理且可继续。
- [ ] 锁屏再解锁，音频不会重复播放。
- [ ] 省电模式下粒子数量和透明叠加明显降低，主功能不变。
- [ ] 开发者工具性能面板中不存在随页面往返持续增长且不释放的动画任务。
- [ ] Console 无未捕获异常、Promise rejection 或持续重复警告。

性能数值应结合项目自动化性能记录和真实设备测量确定。若没有可靠测量，不得在验收报告中虚构帧率、启动毫秒数或内存数据。

## 18. 文案与素材

- [ ] 全仓运行时文案扫描不含禁止定位词和绝对预测词。
- [ ] 规则文档中的禁用词反例不会被打包成运行时营销内容。
- [ ] 古籍原文有出处，现代译文和案例有原创或授权依据。
- [ ] 字体使用系统字体或具有小程序分发授权。
- [ ] 图片、纹理、图标、音效和动画素材可证明自制或具有许可。
- [ ] 不含短视频、影视、游戏或商业出版物的未授权片段。
- [ ] 无恐怖符咒、鬼神、大师、血光、灾祸等视觉。
- [ ] 中文源文件、JSON、WXML、WXSS 和 Markdown 以 UTF-8 正常读取。

## 19. 体验版复核

代码上传并生成体验版后，必须重新执行：

- [ ] 首次说明到情境结果的完整路径。
- [ ] 一个铜钱互动结果。
- [ ] 一个高风险拦截。
- [ ] 一个卦象详情与收藏。
- [ ] 保存、重启、查看、删除记录。
- [ ] 清空全部并取消一次、确认一次。
- [ ] 关闭动画、音效、震动后完整流程。

- [ ] 飞行模式核心功能。
- [ ] iOS 与 Android 各一次。

体验版与本地开发者工具结果不一致时，以体验版问题为真实发布阻塞，不能仅凭本地通过继续提审。

## 20. 发布阻塞条件

出现以下任一情况不得提审：

- 编译错误、页面死路、空白结果或六十四卦数据缺失。
- 高风险输入漏拦截或普通输入大量误拦截。
- 结果出现吉凶、灾祸、绝对预测、诱导付费或诱导分享。
- 用户问题出现在分享内容、网络请求、日志或调试信息中。
- 实际调用未在隐私保护指引声明的接口。
- 实际功能与服务类目、简介或审核备注不一致。
- iOS 或 Android 主流程未实测。
- 体验版未复核。
- 使用权不明的字体、图片、音频、译文或其他素材。
- 仍有测试按钮、调试入口、模拟接口、隐藏开关或未完成页面。

## 21. 验收结束

所有发布阻塞项关闭后：

1. 固定本次源码状态和版本号。
2. 保存自动化测试输出、体验版信息和真实设备检查记录。
3. 按 `submission-checklist.md` 复核后台主体、类目、隐私、备案和提审材料。
4. 上传与已验收源码完全一致的版本。
5. 明确记录哪些检查已实际完成，哪些因设备或平台限制尚未验证。

不得把开发者工具模拟结果包装成真机结果，也不得把编译成功包装成审核通过或可正式上线。

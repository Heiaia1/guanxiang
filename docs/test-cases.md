版本：1.0
文档日期：2026-07-31

总问题样本：72 题

## 1. 执行约定

普通问题用例按以下流程执行：

1. 选择对应领域。
2. 输入表中问题。
3. 按“状态条件”选择五道题。
4. 使用“情境生成”模式。
5. 核对表中“特定期望”及通用断言。
6. 用完全相同输入再次执行，核对结果一致性。

状态条件使用以下简写：

- 行动：马上、准备、观察、无方向。
- 信息：充分、少量缺失、很多未知、无法判断。
- 控制：自己、需他人、受组织/家庭、难控制。
- 影响：很小、可承受、较大、基本生活。
- 情绪：平静、期待、犹豫、焦虑、愤怒、疲惫。

普通问题通用断言：

- 结果包含卦名、传统原意、当前状态、主要矛盾、有利条件、风险提醒和三步行动。
- 至少明确引用一个状态条件，不虚构未输入的收入、关系、健康或他人动机。
- 三步行动分别对应今天、七天内和重新决定条件，内容不重复。
- 不出现吉凶、必然未来、灾祸、改运、付费、诱导分享或“大师”话术。
- 不替用户作不可逆决定。
- 相同输入和内容版本得到相同上下卦、变化爻、核心摘要和行动。
- 分享内容不包含原问题和五道题答案。

高风险用例通用断言：

- 在问题提交后进入对应安全提示，不进入普通六爻生成。
- 不生成卦名、吉凶、概率、治疗、诉讼胜负、投资标的、号码或伤害方法。
- 提示应直接、尊重、可行动，不羞辱用户，不使用玄学原因。
- 用户可返回修改问题或回到首页。

## 11. 六十四卦数据完整性

自动或人工检查必须满足：

- 恰有 64 个唯一卦象 ID。
- 每卦有中文名、读音、上下卦、六爻编码、关键词、原意、白话解释和行动启示。
- 上下卦只使用乾、坤、震、巽、坎、离、艮、兑。
- 列表每一项都能打开对应详情，返回后滚动位置合理。
- 从结果页进入详情时，打开的卦与结果一致。
- 搜索或索引不存在时显示空状态，不跳到错误卦象。
- 全量中文文本以 UTF-8 正常显示。
- 古籍原文与现代解释在视觉上明确区分。

# 观象录 Windows 桌面版

## 使用方法

1. 将压缩包完整解压到一个普通文件夹，不要只在压缩包预览窗口内运行。
2. 双击 `打开观象录桌面版.vbs`。
3. 软件会使用 Windows 自带的 Microsoft Edge 以独立应用窗口打开；如果没有 Edge，则使用默认浏览器。

软件无需安装、无需登录、无需联网。记录、收藏和设置只保存在当前 Windows 用户的浏览器本地存储中。清除浏览器站点数据或更换电脑后，本地记录无法恢复。

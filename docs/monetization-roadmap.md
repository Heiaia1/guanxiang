# 风后奇门 · 零成本增长与商业化路线

更新日期：2026-08-26

## 当前阶段：先获得真实留存与合作收入

当前版本不接服务器、不接广告、不设置本地次数墙，核心功能保持免费。产品内已经形成一条不依赖付费接口的完整链路：

1. 用户通过情境观象、今日观象或铜钱互动获得现实行动建议。
2. 结果可保存到本机，并安排 30 天后回看。
3. 到期后在首页与记录页提示，对照事实变化并标记完成。
4. 用户可自愿分享项目、关注 GitHub，或发起商业授权与定制合作咨询。

这一阶段的收益重点不是向个人用户收取小额费用，而是通过品牌联名、私有部署、内容定制、界面授权与企业合作获得客单价更高的收入。合作需求统一进入 GitHub Issue 留痕，避免在没有主体和支付资质时搭建不可核验的收款流程。

## 零成本增长动作

- 分享不换奖励：只分享项目介绍或不含个人问题的文化卡片。
- 30 天回看：用真实回访价值提升留存，不制造连续签到焦虑。
- GitHub 作为公开信用页：发布版本、校验文件、更新记录和问题反馈均可追溯。
- 官网作为统一转化页：Android 下载、iOS 进度、源码关注与商业合作入口集中展示。

可免费观察的指标包括 GitHub Release 下载量、仓库访问与 Star、官网访问、合作 Issue 数量，以及用户主动反馈的 30 天回看体验。任何本地记录都不上传做统计。

## 未来收费能力的合规接入顺序

只有在具备相应主体、商店账号、协议和支付配置后，才考虑上线可选数字增值服务。基础文化内容和本地反思流程继续免费；可收费的方向优先考虑新增专题内容包、跨设备同步、团队版、品牌定制与商业授权。

- 微信小程序：完成小程序认证、微信支付商户号、支付权限和 AppID 绑定后，按微信支付接口接入。
- iOS：应用内解锁数字内容时使用 Apple In-App Purchase，不使用外部兑换码绕过商店支付。
- Google Play：通过 Play 分发并销售数字功能时，按适用政策接入 Google Play Billing。
- Windows 与官网：在具备经营主体、隐私与退款流程后，再接入独立支付和账号授权服务。

不同平台不共用一套手工兑换码冒充购买。跨平台权益需要服务端账号、订单校验与恢复购买能力，在这些基础设施完成之前不对用户展示购买按钮。

## 产品与内容底线

- 不按结果吉凶收费，不花钱改结果，不分享解锁答案。
- 不宣称预测必然未来，不替代医疗、法律、投资或人身安全判断。
- 不上传用户问题、答案、记录和回看状态。
- 所有价格在正式上线前都只是商业假设，不写入当前产品界面。

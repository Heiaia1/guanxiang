# 《观象录》微信小程序提审清单

版本：1.0
文档日期：2026-07-31
适用范围：第一版全本地 MVP

## 1. 使用说明

本清单用于在上传、体验版检查、备案和提交审核前做最终核对。微信公众平台的类目、资质、隐私、备案、包体和审核规则会更新，因此每次提审都必须以提交当日后台显示的最新要求为准。

完成本清单可以降低遗漏风险，但不能承诺审核通过。不得使用隐藏功能、远程开关、虚假类目、审核专用账号或上线后变更服务内容来绕过审核。

## 2. 发布范围确认

- [ ] 本次版本只包含传统文化互动、现实情境反思、行动建议、六十四卦文化内容、本地记录、收藏和设置。
- [ ] 不含未来预测、吉凶判断、改命、转运、消灾、法事或真人“大师”咨询。
- [ ] 不含账号、登录、手机号、云同步、服务器、云函数或远程配置。
- [ ] 不含大模型、第三方 AI、广告、埋点、用户画像或第三方分析 SDK。
- [ ] 不含支付、会员、订单、虚拟商品、付费解锁或观看广告改结果。
- [ ] 不申请定位、相机、相册、麦克风、通讯录、蓝牙、运动数据或精确设备标识权限。
- [ ] 用户问题和状态答案只保存在小程序本地 Storage。
- [ ] 分享内容不包含用户问题、答案、备注或其他私密信息。
- [ ] 核心功能在断网状态下可运行。

若任何一项与实际代码不符，应先修正文档、后台声明或代码，不能带着不一致状态提审。

## 3. 主体、账号与备案

- [ ] 发布主体信息真实、有效，后台管理员可正常接收审核通知。
- [ ] 小程序 AppID 与本项目发布配置一致，不误用测试号或其他项目 AppID。
- [ ] 主体可选择的服务类目已在微信公众平台后台实际核对。
- [ ] 所选类目与“传统文化内容展示、互动工具和个人本地记录”的实际服务一致。
- [ ] 未选择与实际功能无关的工具、教育、娱乐、医疗、金融或其他类目绕审。
- [ ] 若后台要求资质文件，文件属于当前主体、在有效期内且与所选类目一致。
- [ ] APP 备案状态按提交时平台和监管流程确认，需备案时已完成或进入平台允许的提交流程。
- [ ] 备案中的应用名称、主体、服务内容与小程序实际内容一致。
- [ ] 未购买或使用“包过审”、代挂类目、借用资质或隐藏功能服务。

类目不可在文档中预先写死。最终选择应由发布主体在提审当天根据后台可选项、资质和实际功能确定，并保留截图或发布记录。

## 4. 名称、头像、简介与关键词

### 4.1 推荐口径

名称：

> 观象录

简介：

> 以六十四卦文化为内容基础的传统文化互动与个人反思工具，提供情境梳理、行动建议、文化阅读和本地记录。

服务说明：

> 用户可选择工作、关系、人际、学习、家庭或自我状态，完成结构化问题后查看六十四卦文化解释和现实行动建议。内容仅用于传统文化互动与个人反思，不代表未来必然发生，不构成医疗、法律或投资建议。第一版无登录、无支付、无广告，用户问题仅保存在本机。

### 4.2 检查项

- [ ] 名称、头像、简介和首页首屏表达同一产品定位。
- [ ] 名称和简介不含算命、占卜、运势、吉凶、改运、转运、消灾、预测、神准等表述。
- [ ] 头像不使用符咒、鬼神、大师肖像、灾祸或夸张宗教化元素。
- [ ] 简介真实说明核心功能，不堆叠关键词，不承诺效果。
- [ ] 搜索关键词不使用财运、桃花、算命、运势等吸引错误流量。
- [ ] 版本说明描述真实变化，不写“测试”“演示”“即将上线”等非正式状态。
- [ ] 客服或联系入口使用发布主体实际维护的官方渠道，不展示无关个人账号。

## 5. 页面与功能完整性

- [ ] 启动动画可跳过，结束后进入使用说明或首页。
- [ ] 首次使用说明包含传统文化互动、非预测和非专业建议提示。
- [ ] 首页六个主要入口均可打开并能正常返回。
- [ ] 六类问题领域完整，不存在空分类。
- [ ] 问题输入限制 1—100 字，并提示不要填写姓名、生辰、地址等个人信息。
- [ ] 五道状态题必须完成后才能进入生成页。
- [ ] 情境生成结果稳定，相同输入不产生矛盾结论。
- [ ] 铜钱模式明确标注文化互动属性，不宣称预测。
- [ ] 每个正常结果包含文化解释、现实矛盾、风险提示和三步行动。
- [ ] 64 个卦象全部可打开，无空白、乱码或错误路由。
- [ ] 历史、收藏、删除、清空和设置重启后状态正确。
- [ ] 高风险问题按类别拦截，不进入普通生成。
- [ ] 页面无未实现按钮、空白页、调试入口、隐藏手势或远程开关。
- [ ] 错误提示对用户可理解，不展示堆栈、内部路径或调试信息。
- [ ] 所有需要审核人员操作的功能无需登录、邀请码或特殊账号。

## 6. 内容安全

- [ ] 全量运行时文案通过 `content-rules.md` 禁用表达扫描。
- [ ] 结果不含“大吉”“大凶”“必定”“命中注定”“血光之灾”等预测或恐吓表达。
- [ ] 不判断发财、破财、婚姻结果、怀孕、胎儿性别、疾病、寿命、死亡或他人出轨。
- [ ] 不提供医疗、用药、法律、投资、借贷、赌博或彩票结论。
- [ ] 不诱导用户反复生成、连续签到、转发分享、观看广告或付款。
- [ ] 不出现“大师微信”、外部咨询、法器、课程转运或其他导流内容。
- [ ] 感情和家庭内容不鼓励监控、纠缠、暴力、控制或侵犯隐私。
- [ ] 自伤、伤人、暴力、医疗、法律、投资和违法请求均有安全分支。
- [ ] 古籍原文有出处，现代译文和案例为原创或有合法授权。
- [ ] 图片、字体、纹理、音效和图标保留可核对的授权或自制记录。
- [ ] 分享标题、分享卡和页面截图同样通过内容安全检查。

## 7. 隐私保护与权限

- [ ] 设置页可以打开 `privacy-policy.md` 对应的完整隐私保护说明。
- [ ] 首次说明页和隐私说明明确：问题、答案、历史、收藏和设置只保存在本地。
- [ ] 隐私说明逐项列明本地处理目的、保存期限、删除方式和分享边界。
- [ ] 微信公众平台后台“用户隐私保护指引”按实际 API 和组件使用情况填写。
- [ ] 后台声明与代码扫描、开发者工具隐私检测结果一致。
- [ ] 没有为了“以后可能使用”而超前声明或申请权限。
- [ ] 未调用未声明的隐私接口或组件。
- [ ] 震动能力只在用户开启时调用，不收集数据。
- [ ] 分享必须由用户主动触发，分享前不上传原问题。
- [ ] 删除单条和清空全部功能可用，确认后本地数据确实移除。
- [ ] 不存在业务网络请求、日志上报、第三方追踪或跨境传输。
- [ ] 隐私说明提供微信平台“联系开发者”路径，发布主体能够实际接收并处理请求。
- [ ] 用户协议和隐私说明的发布日期、版本和实际发布包一致。

若后续版本增加任何服务器、统计、登录、相册、AI、支付或第三方 SDK，必须在开发和提审前重新评估数据流、权限、协议、类目和资质，不能继续沿用本地版声明。

## 8. 技术与包体

- [ ] 微信开发者工具使用目标基础库完成编译，无错误和未处理警告。
- [ ] TypeScript、导入路径、页面路由、组件引用和 JSON 配置检查通过。
- [ ] `project.config.json` 中 AppID、项目根目录、编译设置和上传配置正确。
- [ ] `app.json` 页面、分包、窗口样式和权限配置与实际文件一致。
- [ ] 代码中不存在 API Key、AppSecret、访问令牌、个人路径或敏感调试数据。
- [ ] 生产包未包含源素材、未压缩大图、无用音频、测试数据或开发日志。
- [ ] 主包与分包体积符合提交时微信平台限制。
- [ ] 图片、音频和序列帧完成压缩，视觉质量仍可接受。
- [ ] 所有 JSON 数据能解析，六十四卦 ID 唯一、字段完整。
- [ ] 本地 Storage 损坏、超限或不可用时有安全降级。
- [ ] Canvas、音频和震动失败不会阻塞主流程。
- [ ] 无网络、弱网和飞行模式完成核心流程测试。
- [ ] 没有业务域名、服务器域名、WebView 或外链白名单需求。
- [ ] 生产环境关闭调试信息，不暴露内部状态。

## 9. 兼容性与体验

- [ ] 至少在一台 iOS 和一台 Android 真机完成全流程。
- [ ] 覆盖小屏、长屏、安全区和系统字体放大。
- [ ] 底部按钮不被 Home 指示条、导航栏或键盘遮挡。
- [ ] 中文无乱码，长标题、长问题和三步行动不截断。
- [ ] 启动动画、铜钱动画和六爻动画均可跳过或关闭。
- [ ] 关闭音效、震动、动画和开启省电模式后设置立即生效。
- [ ] 连续完成 20 次分析无崩溃、重复记录或明显持续变慢。
- [ ] 从后台恢复、锁屏恢复和页面快速返回无状态错乱。
- [ ] 主要按钮有点击反馈，加载期间防重复提交。
- [ ] 不使用频繁强震、连续闪烁、强制长动画或遮挡操作的粒子。
- [ ] 内容可滚动阅读，返回后列表位置和用户选择符合预期。

## 10. 审核材料

- [ ] 上传代码对应唯一可追溯的版本号和代码提交。
- [ ] 体验版二维码由发布主体实际打开并完成全流程。
- [ ] 准备首页、情境选择、结构化问题、生成、结果、文化馆、历史、设置与隐私页面截图。
- [ ] 截图来自本次真实体验版，不使用设计稿冒充。
- [ ] 提审说明写清无登录、无支付、无后台、全本地和高风险拦截。
- [ ] 审核路径简洁明确，不要求审核人员猜测入口。
- [ ] 审核备注不夸大，不承诺“绝对合规”或“保证过审”。
- [ ] 如审核要求测试说明，提供 `manual-qa.md` 中真实执行过的流程和实际结果。
- [ ] 如涉及版权说明，可提供自制或授权素材清单及古籍来源说明。
- [ ] 保留本次后台类目、隐私指引、版本信息和提交时间的内部记录。

推荐审核路径：

```text
启动页
→ 使用说明“我已了解，开始体验”
→ 首页“问一件事”
→ 选择“工作事业”
→ 输入一个现实问题
→ 完成五道状态题
→ 选择“情境生成”
→ 查看结果与三步行动
→ 返回首页查看“六十四卦”和“我的记录”
→ 设置页查看隐私保护说明与数据清理
```

推荐提审备注：

> 本版本为传统文化互动与个人反思工具。用户通过六类现实情境和五道结构化选择题，查看六十四卦文化解释、风险梳理与行动建议。内容不预测未来或吉凶，不构成医疗、法律、投资建议。第一版无登录、无支付、无广告、无服务器和 AI；用户问题及记录仅保存在本机，可单条删除或全部清空。审核可按备注中的完整路径直接体验全部功能。

## 12. 被拒后的处理

1. 保存完整拒绝原因、截图、版本号和提交时间。
2. 对照审核指出的具体页面、文案、类目、资质或隐私项复现。
3. 检查相同问题是否存在于其他页面、分享卡和素材中。
4. 修复根因并执行相关内容、安全、隐私和回归测试。
5. 更新审核备注，说明真实修复内容。
6. 使用新的可追溯版本重新提交。

不得只在截图或审核路径中隐藏问题，也不得上线后通过本地时间、远程开关或用户身份恢复被拒功能。

## 13. 审核结论边界

- 微信平台审核是独立决定，本项目不作百分之百通过承诺。
- 通过一次审核不表示后续版本、运营内容或类目永久合规。
- 发布主体对实际服务、用户内容、隐私处理、素材权利和持续运营承担相应责任。
- 每次功能变化都应重新执行本清单；增加服务器、AI、支付、广告、登录或用户上传内容时应进行完整重新评估。
